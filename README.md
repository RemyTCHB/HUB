## What It Does

Plan the work, assign it, and watch it move — together, in real time.

- **Two Company Boards** — TCHB and KPI DRIVER, each with its own tasks, progress, and brand look.
- **Tasks & Subtasks** — check off subtasks and the main task closes itself, or complete the whole task in one click.
- **Clear Statuses** — Not Started, In Progress, Done.
- **Owners** — assign every task and subtask; add new teammates in a click.
- **Filters** — by status and by owner.
- **Drag To Reorder** — put priorities where they belong.
- **Edited By** — see who changed what, and when.
- **Light & Dark Themes** — your preference, remembered.
- **Live For The Whole Team** — updates appear for everyone within seconds.

## Access

## Deployment

Hosted on **Vercel**, connected to this repository. Every commit to `main` redeploys automatically.

## Updating

1. Export the latest `index.html` from the design project.
2. Replace it in this repo and commit.
3. Vercel publishes the update in about 30 seconds. Task data is stored separately and is never affected by updates.
